# BUG-002. Окно оплаты остаётся на экране при навигации «назад/вперёд»

| Поле | Значение |
|---|---|
| **Окружение** | Chrome, Узбекистан (/ru-uz), 03.10.2026 |
| **Серьёзность** | Low–Medium |
| **Приоритет** | Low |
| **Статус** | Подтверждено (воспроизведено повторно, 03.10.2026) |

## Предусловия
Выполнен вход через Yandex ID.

## Шаги воспроизведения
1. Открыть hd.kinopoisk.ru/ru-uz
2. Нажать «Попробовать бесплатно», чтобы открыть окно подключения подписки
3. Несколько раз нажать кнопки «назад» и «вперёд» в браузере

## Ожидаемый результат
Окно закрывается, либо страница за ним не меняется.

## Фактический результат
Окно подключения остаётся поверх страницы, а страница за ним меняется (главная, «Подписки», «Каналы»).
