# Тест-план: Кинопоиск

**Дата:** 03.10.2026
**Тип тестирования:** ручное, функциональное и UI

## 1. Цель
Проверить основной пользовательский путь: найти фильм или сериал, открыть его страницу, дойти до просмотра, включая вход в аккаунт и оформление подписки.

## 2. Объект тестирования
- kinopoisk.ru: главная страница, раздел «Списки», поиск
- hd.kinopoisk.ru/ru-uz: онлайн-кинотеатр, каналы, подписки, окно оплаты
- Вход через Yandex ID

## 3. Что тестируем
1. Навигация (меню, вкладки, переходы между kinopoisk.ru и hd.kinopoisk.ru)
2. Поиск: обычные запросы, спецсимволы
3. Списки и подборки: названия, подписи, актуальность
4. Страница каналов: категории
5. Доступ без авторизации
6. Окно оплаты подписки: ввод карты, ошибки, поведение окна

## 4. Что не тестируем
- Успешное списание денег и работу самой подписки
- Потоковое воспроизведение видео
- Покупку билетов в кино
- Нагрузку и безопасность

## 5. Окружение
| Параметр | Значение |
|---|---|
| Браузер | Chrome (версию указать) |
| Разрешение | 2560×1440 |
| Регион | Узбекистан, версия `/ru-uz` |
| Авторизация | без входа и с входом через Yandex ID |

## 6. Подход
- Исследовательское тестирование, затем оформление шагов в тест-кейсы
- Негативные проверки: спецсимволы в поиске, неверные данные карты
- Все отклонения фиксируются скриншотом и повторно проверяются

## 7. Критерии завершения
- Пройден чек-лист по всем разделам
- Каждое отклонение оформлено как баг-репорт или наблюдение
- Результаты сведены в таблицу

## 8. Риски
| Риск | Влияние | Что делаем |
|---|---|---|
| Контент и баннеры меняются | Результаты могут не повториться | Фиксировать дату и скриншот |
| Реклама и блокировщики | Пустые блоки, искажение вёрстки | Проверять с отключёнными блокировщиками |
| Платёжный сценарий | Риск реального списания | Не использовать реальную карту без необходимости, проверять выписку |
| Защита от ботов | Автоматизация невозможна | Только ручное тестирование |
