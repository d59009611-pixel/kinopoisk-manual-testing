# Kinopoisk QA: ручное тестирование

Учебный проект по ручному тестированию сервиса [Кинопоиск](https://www.kinopoisk.ru) и его онлайн-кинотеатра (hd.kinopoisk.ru). Тестирование проводилось на публичной версии сайта, без доступа к исходному коду.

## Что внутри

| Файл | Содержание |
|---|---|
| `01-test-plan.md` | Тест-план: цели, объём, окружение, риски |
| `02-checklist.md` | Чек-лист по разделам сайта |
| `03-test-cases.md` | Тест-кейсы с результатами прогона |
| `04-bug-reports/` | Баг-репорты по найденным проблемам |
| `screenshots/` | Скриншоты-доказательства (личные данные закрыты) |
| `kinopoisk_findings.xlsx` | Сводная таблица находок и результатов |

## Итоги прогона (03.10.2026)

- Проверок: 10 (Pass: 5, Fail: 5)
- Баг-репортов: 6, все подтверждены. Самый серьёзный: BUG-006 (списание 15 999 сум при заявленных 0 сум)
- Что проверялось: главная страница, списки и каталог, поиск, вход через Yandex ID, окно оплаты подписки, страница каналов

## Как читать результаты

Баги BUG-001…005 воспроизведены повторно (статус «Подтверждено» в каждом репорте). BUG-006 подтверждён данными платёжного приложения.

## Окружение

- Браузер: Chrome
- Регион: Узбекистан (hd.kinopoisk.ru/ru-uz, цены в сумах)
- Режим: сначала без авторизации, затем с входом через Yandex ID

## Навыки, показанные в проекте

Составление тест-плана, чек-листа и тест-кейсов, негативное тестирование (спецсимволы, неверные платёжные данные), оформление баг-репортов, приоритизация находок.

## Ограничения

Автоматизацию не делал: на сайте есть защита от ботов. Платёж получился случайно, при проверке с реальной картой (BUG-006). Скриншоты лежат в `screenshots/`, личные данные на них закрыты.
