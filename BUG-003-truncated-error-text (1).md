# BUG-003. Текст ошибки карты обрезан: «Используйте дру…»

| Поле | Значение |
|---|---|
| **Окружение** | Chrome, Узбекистан (/ru-uz), разрешение 2560×1440, 03.10.2026 |
| **Серьёзность** | Low–Medium |
| **Приоритет** | Low |
| **Статус** | Подтверждено (воспроизведено повторно, 03.10.2026) |

## Предусловия
Открыто окно подключения подписки Яндекс Плюс.

## Шаги воспроизведения
1. В поле «Номер карты» ввести тестовый номер, который сервис не поддерживает
2. Посмотреть на подсказку под полями «Действует до» и «Код»

## Ожидаемый результат
Подсказка видна полностью и объясняет, что делать.

## Фактический результат
Подсказка обрезана на середине слова: «Эта карта не поддерживается. Используйте дру…». Окно широкое, значит дело не в узком экране.
