# BUG-001. На странице «Каналы» категория «Детские» повторяется дважды

| Поле | Значение |
|---|---|
| **Окружение** | Chrome, Узбекистан (/ru-uz), 03.10.2026 |
| **Серьёзность** | Low–Medium |
| **Приоритет** | Low |
| **Статус** | Подтверждено (воспроизведено повторно, 03.10.2026) |

## Предусловия
Открыта страница hd.kinopoisk.ru/ru-uz/channels, поиск закрыт.

## Шаги воспроизведения
1. Открыть hd.kinopoisk.ru/ru-uz/channels
2. Посмотреть на ряд категорий под заголовком «Смотреть каналы»

## Ожидаемый результат
Каждая категория отображается один раз.

## Фактический результат
В ряду «Кино и сериалы, Познавательные, Детские, Детские, Развлекательные» категория «Детские» встречается два раза подряд.
